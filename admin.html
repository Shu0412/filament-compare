后台能看到什么

每日浏览趋势按天查看访问量变化，适合观察内容更新后的效果。
独立访客查看多人访问规模，不把同一用户的多次打开简单相加。
来源与热门页面知道访客从哪里来、最常打开哪个页面。
统计边界：原第三方计数器只提供累计徽章，不提供按天后台 API；所以本页不会伪造“今日帮助人次”。如果你希望把 GitHub Pages 的实际访问按天直接画在本站内，还需要再绑定一个 Cloudflare Web Analytics 或 Umami 的站点 ID。
