# 🧪 Filament Lab · 丝验室 · 3D 打印耗材对比库

> 🧡 内容创建：舒舒 · 基于 DeepSeek Harness 构建 · 开源免费
> 🌐 **永久网址（GitHub Pages）**：https://shu0412.github.io/filament-compare/
> 电脑关机也能访问，分享给朋友永不失效；内容更新后重新部署约 1 分钟生效。

面向 3D 打印玩家的耗材可视化对比站点：**常规耗材 / 工程耗材**两大分区，
覆盖 PLA 家族、PETG、ABS、ASA、TPU、PA、PC、POM、PPS、PEEK、PEI 等 **37 种主流耗材**（含丝绸/木质 PLA、PETG-CF、PA12-CF、PET-CF、PPS-CF、PPA-CF、PC-ABS、PEBA、BVOH 等），
从**物理性能**（Tg/Tm/HDT/拉伸/冲击/伸长率/密度/吸湿）、**打印便利性**（温度/难度/翘曲/腔体/干燥）、
**安全性**（释放物/通风/过滤/封闭腔体）三个维度对比，并收录 **10 大品牌**（拓竹 · Kexcelled(诺思贝瑞) · 三绿(Sunlu) · Polymaker · eSUN · Prusament · 创想三维 · 纵维立方 · Overture · 3DXTech）官方产品线。

## 功能
- 材料卡片总览（关键参数 + 综合评分 ⭐ + 难度/安全/翘曲标签）
- 搜索与多维筛选（关键词 / 难度 / 安全等级 / 材料家族）
- 选材向导：8 大使用场景一键推荐
- 材料详情弹窗：全字段数据 + 安全说明 + 数据来源
- 交互对比工具：多选 2–5 种耗材 → 雷达图画像 + 条形图 + 可排序数据表（🏆 每列最优高亮）
- 品牌专区：10 大品牌官方在售材料线
- 打印安全指南：各材料释放物与防护建议
- 亮/暗主题切换、回到顶部
- 数据说明 + 矫正记录：每次数据更新均逐项复核上一版本并留痕

## 本地运行
```bash
python3 -m http.server 8000        # 打开 http://127.0.0.1:8000
```

## 公网分享（免账号）
一键安装**常驻服务**（开机自启 + 崩溃自愈 + 公网隧道）：
```bash
./install-service.sh   # 安装并启动，输出公网地址
./url.sh               # 随时查看当前公网地址（隧道重启后地址会变，用这个查）
./status.sh            # 查看服务状态
./stop-service.sh      # 停止服务（可随时重新安装）
```
或手动临时方式：
```bash
cloudflared tunnel --url http://127.0.0.1:8000
```

> ⚠️ 免费隧道（trycloudflare）在隧道进程重启（如电脑重启）后会生成新地址，
> 请运行 `./url.sh` 获取最新地址；局域网内（同一 WiFi）可用 `http://<本机IP>:8000` 访问。
> 需要**永久固定网址**（电脑关机也能访问）时，请提供 GitHub 账号 token，可迁移到 GitHub Pages。

## 数据口径
- 所有数值为**典型区间**，来源：厂商官方 TDS、Prusa 材料库、Simplify3D、Polymaker/eSUN/Bambu Lab 官方 Wiki 与权威第三方测试。
- 打印件实测与注塑级树脂数值差异显著（如 PC 伸长率 3% vs 60%+），已按打印件口径优先并注明。
- 具体牌号/批次可能有差异，工业/关键应用请以厂商正式 TDS 为准。
