🛡️ 打印安全指南

📖 通用安全建议（点击展开）

通用安全建议

  • 🪟 无论打印何种耗材，都应在通风良好的空间打印；长时间打印建议使用 HEPA + 活性炭过滤器。
  • 🔥 ABS / ASA / HIPS 会释放苯乙烯，务必通风或封闭腔体 + 过滤。
  • ⚠️ POM 高温下释放甲醛，PEEK/PEI 等高温材料释放物浓度更高，必须使用封闭腔体 + 强通风 + 过滤。
  • 🧒 打印区域应远离儿童与孕妇，颗粒物粒径小，可深达肺部。
  • 🏠 长期在卧室打印会显著提高室内颗粒物浓度，建议专用房间或通风柜。
  • 🧴 高温材料（PA/PC/PEEK 等）打印时请佩戴耐高温手套防止烫伤，接触皮肤前先冷却。

📏 数据口径

  • 所有数值均为典型区间（min–max），来源为厂商官方 TDS、Prusa 材料库、Simplify3D 指南及权威第三方测试；同一材料不同牌号/批次实测值可能超出区间。
  • 抗冲击强度单位以 IZOD 缺口冲击为主，个别材料标注 J/m；跨单位比较仅供参考。
  • 打印难度 1–5：1 = 入门机轻松打印；5 = 需高温工程机 + 封闭腔体 + 干燥等专业条件。
  • 雷达图得分为各维度归一化结果（按区间上限归一），仅用于横向比较趋势，不代表绝对优劣。
